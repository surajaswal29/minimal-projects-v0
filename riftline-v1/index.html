How Riftline works without JavaScript

  1. Steering is a radio group. Five hidden radios are the lanes. Arrow keys move between radios natively, and :has(#l3:checked) turns the ship to that lane.
  2. Jumping is :active. Holding Space on the focused radio makes it :focus-visible:active. A mouse click on a radio's label is not :focus-visible, so steering never counts as a jump.
  3. The course is a timeline on <html>. A stepped animation per lane sets a typed @property (0 clear, 1 wall, 2 fence, 3 laser) for the 0.18 s each hazard overlaps the ship.
  4. Collision is a style query. @container style(--l3: 1) { body:has(#l3:checked) { … } } is true only while you are in lane 3 and a wall is there.
  5. Damage latches. That rule un-pauses a shield "drain" animation on <body>. Paused animations keep their progress, so damage adds up and never comes back. When it ends, --dead flips to 1 and the world freezes.
  6. Every object latches too. A 50 ms animation on each shard or hazard runs only while it is hot and you are in its lane. Its end state sets --boom for the explosion and a counter-increment for the score.
  7. The ship banks on its own. Two nested rotations, one instant (−1.4 × lane angle) and one with a slow transition (+1.4 ×), add up to a roll into each turn that settles back to level.
