Under the hood

  • Targets are <label>s for hidden checkboxes. Clicking one checks it, which triggers the explosion and pauses its flight path.
  • Score is a CSS counter: .hit:checked { counter-increment: score 1 }, printed with content: counter(score).
  • Timer animates an integer @property --t from 60 to 0.
  • Game over is an overlay with animation-delay: 60s.
  • 3D: perspective, transform-style: preserve-3d and separate translate / scale / rotate animations.
  • Game state (start, pause, difficulty) is read with :has(). Restart is a native <button type="reset">.
  • Logo is a declarative shadow DOM <template shadowrootmode> component.
