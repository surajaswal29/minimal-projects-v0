Under the hood

How it fits together

Show the five techniques
  1. Forms → iframe: <form target="name"> updates a single region.
  2. Self-rendering form: the reply is a new copy of the form.
  3. Streaming: the server never closes the response, so the HTML keeps growing.
  4. Polling: meta refresh reloads a single frame.
  5. CSS beacons: :has(:checked) + url() send a GET request.
